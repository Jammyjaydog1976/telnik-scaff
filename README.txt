TELNIK SCAFF V1 WORKING PROTOTYPE

Open index.html in a browser.
Current functions:
- Today dashboard
- Scaffold register with automatic 7-day inspection cycle
- 2-day / 1-day / due today / overdue tag status
- New-job site visit checklist
- JC / CF / Both management tasks
- Pricing and job-costing calculator
- Data saved locally in the browser

This is a prototype. Multi-user syncing, secure login, cloud storage, push notifications,
photo/document uploads and production iPhone deployment require a backend and app deployment.
